用户隐私协议

欢迎您使用我们的应用程序！我们非常重视您的隐私保护和个人信息安全。本隐私协议旨在向您说明我们如何收集、使用、存储和共享您的个人信息，以及您享有的相关权利。

一、信息收集

我们可能收集以下类型的信息：

  • 个人信息：当您注册账户时，我们会收集您的用户名、手机号码等基本信息。
  • 使用数据：包括您的浏览记录、搜索记录、学习进度等应用内活动信息。
  • 设备信息：如设备型号、操作系统版本、唯一设备标识符等技术信息。
  • 位置信息：在您授权的情况下，我们可能会获取您的位置信息以提供相关服务。

二、信息使用

我们收集的信息将用于以下目的：

  1. 提供、维护和改进我们的服务；
  2. 开发新的功能和服务；
  3. 个性化您的用户体验；
  4. 发送技术通知、更新和安全提示；
  5. 监测和分析使用模式及趋势；
  6. 检测、预防和解决技术问题及安全问题。

三、信息存储与保护

我们采取适当的技术和管理措施来保护您的个人信息免受未经授权的访问、披露、修改或破坏。所有数据存储都遵循严格的安全标准，并定期进行安全评估。

四、信息共享

我们不会将您的个人信息出售给第三方。仅在以下情况下可能共享信息：

  • 获得您的明确同意；
  • 为遵守法律法规要求；
  • 与我们的服务提供商合作（这些第三方必须遵守同等水平的隐私保护义务）；
  • 在法律要求或允许的情况下，为保护我们的权利、财产或安全。

五、您的权利

您有权：

  • 访问、更正或删除您的个人信息；
  • 撤回对我们处理您个人信息的同意；
  • 要求我们限制处理您的个人信息；
  • 获取您个人信息的副本；
  • 注销您的账户。

六、儿童隐私

我们的服务面向一般人群，不专门针对13岁以下的儿童。如果我们发现无意中收集了儿童的个人信息，我们将尽快删除相关信息。

七、协议更新

我们可能会不时更新本隐私协议。当变更发生时，我们会在应用内发布新版本并通过适当方式通知您。请您定期查阅本协议以了解最新的隐私实践。
