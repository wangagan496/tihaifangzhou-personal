# 朗读、桌面卡片与 AI 评分

## 当前接入范围

- 题目/面经详情：朗读题干和正文；普通题可进入回答评分，自动带入题目与参考答案。
- 录音文字稿：朗读已生成的文字；进入评分页核对和编辑回答，再填写对应题目。评分页修改不会覆盖原录音文字稿。
- 我的：新增 AI 回答评分和桌面卡片添加说明。
- 桌面学习快捷卡片：2×2 / 2×4，提供题库、收藏、录音三个入口。卡片不展示账户、录音、文字稿或学习记录。不是每日题目/动态学习统计卡片。

## 离线朗读

使用当前 API 24 SDK 的 `@kit.CoreSpeechKit.textToSpeech`，`language: zh-CN`、`person: 0`、`online: 1`。清理 HTML 后按不超过 400 个 UTF-16 单元拆段，避免拆开代理对，依次播放；只将 `onComplete.type === 1` 视为播放完成。

初始化超时 20 秒，每段最长等待 180 秒。切题、离页、应用后台和主动停止会取消任务并关闭引擎。停止前先使回调失效，防止系统先触发完成回调又继续播放下一段。设备没有离线语音能力时显示可重试错误，不切换到云端朗读。

## 桌面入口

桌面长按应用图标，在服务卡片中选择「学习快捷卡片」。`StudyFormAbility` 注册在模块配置中，`StudyCard` 通过 `postCardAction` 发送 `studyCardAction`。`EntryAbility` 只接受 `questions`、`favorites`、`audio` 三个值。

冷启动会暂存动作，由 Index 的 `onPageShow` 在路由页真正就绪后消费，不能仅依赖 `loadContent` 的完成回调；热启动通过 `onNewWant` 执行。收藏和录音沿用 `auth.checkAuth` 的登录回跳规则。题库入口回到首页 Tab。未知动作不导航；不会把外部传入值直接当路由。

## AI 评分：独立后端已实现，真实模型待配置

仓库新增 TypeScript + Fastify 后端 `backend/`。Debug 和 Release 的 `AI_SCORING_URL` 默认仍为空，客户端不会自动发送请求；后端未配置真实模型时返回 503，不生成模拟分数。启动、模型配置和服务访问码见 [后端说明](../backend/README.md)。

客户端配置独立服务的完整 HTTPS URL，固定路径 `/v1/scores`。独立服务访问码在「我的 → 设置 → 评分服务配置」中一次保存，评分页自动读取；不会转发课堂登录 token。客户端使用 Asset Store 的 SECRET 字段加密保存，按账号与服务地址隔离、解锁后读取、禁止云同步；设置页不回显已保存的值，并支持更新和清除。模型 API 密钥仍只放在后端环境变量。

### 已实现请求契约

`POST /v1/scores`，JSON；使用独立服务访问码作为 Bearer token。题目最多 2000 字，回答和参考答案各最多 20000 字。

```json
{
  "question": "如何防止旧请求覆盖新题？",
  "answer": "使用请求序号，只接受当前请求的响应。",
  "referenceAnswer": "参考答案可以为空"
}
```

成功必须返回 HTTP 200、业务码 10000、`success: true`，及以下结构；`score` 必须为 0–100 的有限数值，0 分是有效结果。以下分数仅为接口文档示例，不是实际调用结果。

```json
{
  "code": 10000,
  "success": true,
  "data": {
    "score": 75,
    "summary": "覆盖了核心思路，可以补充生命周期处理。",
    "strengths": ["提到了请求序号"],
    "improvements": ["补充离页取消和过期响应处理"]
  }
}
```

`summary` 非空且最多 4000 字；亮点和建议均为最多 10 条的字符串数组，每条非空且最多 2000 字。无效结构整体拒绝。后端已处理模型调用、密钥隔离、输入校验、超时和限流，不保存答案；模型质量和提供方数据保留策略仍需另行确认。

### 数据与请求行为

- 提交前显示服务地址和发送内容，并告知会再提交给其模型提供方；经用户确认才发送，不上传音频文件。
- 客户端最长等待 60 秒，通过 Axios `AbortController` 取消；后端默认 45 秒超时，并传播客户端断开。两端均禁止重定向。
- 不自动重试；取消、离页或账号/token 变化后不接收旧结果。取消客户端等待不代表服务端已经终止。
- 网络错误保留输入；编辑后清除旧评分；评分仅在当前页面内存中展示，不写入录音数据库。
- AI 仅分析回答文字，不声称评价声音、语气或语速。真实端到端评分需等后端接入后另行验收。
